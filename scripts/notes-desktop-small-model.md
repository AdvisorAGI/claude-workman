# Desktop notes for a small model driving this Mac

Measured on this machine, not guessed. Each line is here because ignoring it
cost a run.

## Clicks
- A click on a text field that is ALREADY focused changes no pixels. If you
  are told "nothing changed" right after clicking a search box or text field,
  the click probably LANDED. Do not re-aim at it. Type instead.
- Never send the same click twice in a row. If a click did nothing, either
  type, or pick a visibly different target.
- A click that brings a different window to the front was the wrong target,
  even though the screen changed a lot.

## Text fields
- To replace text that is already in a field: press cmd+a, then type. Typing
  without cmd+a appends to what is there and produces a mangled query.
- After typing into a search box, press Return to commit it. A suggestion
  list hanging open is not a result list.

## Getting to a page
- Prefer open_url over clicking through navigation. It focuses Chrome, uses
  the address bar and loads the page in one action.
- To leave a wrong page, open_url the page you want. Do not hunt for a back
  arrow.
- Escape closes an open menu or suggestion list. In a browser it also leaves
  fullscreen, so do not press it to tidy up.

## Reading
- Read small text by looking again at that region rather than guessing from a
  downscaled picture.
- Report only what is actually on the screen. If a row is cut off, say the
  part you can see rather than completing it from memory.

## Finishing
- Call done as soon as the task is answerable. Extra steps after the answer
  is visible only risk changing the screen.
- If three actions in a row change nothing, stop and say what is blocking you
  instead of continuing to click.
